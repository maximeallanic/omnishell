# Getting help

- **A question or an idea**: open a [Discussion](https://github.com/maximeallanic/gnome-google-hub/discussions).
- **Something is broken**: open an [issue](https://github.com/maximeallanic/gnome-google-hub/issues/new/choose) with
  the bug report form (version, distribution, GNOME Shell version, output of `verify.sh`).
- **A security problem**: do not open a public issue, see [SECURITY.md](SECURITY.md).

Before you ask, run `~/.local/share/google-hub/source/verify.sh` and read
[docs/troubleshooting.md](docs/troubleshooting.md): they answer most problems. This is a volunteer project: answers
are best effort, usually within a week.
